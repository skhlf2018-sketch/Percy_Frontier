# Percy Frontier

PC 1인칭 오픈월드 액션 RPG. 총기로 몬스터의 약점과 장갑을 부수고, 몬스터에게서 분석한 스킬로 전투를 넓히며, 지도에 표시되지 않는 존재를 흔적으로 추적하는 게임입니다. 전체 기획은 [통합 기획서](docs/design/Percy_Frontier_통합기획서.md)에 있습니다.

## 현재 단계: 퍼시 외곽권 슬라이스 (v0.3.0)

전투 시험(v0.1.0) 다음 단계로, **『샹그릴라 프론티어』의 구조와 감각**(세계·분위기, VRMMO식 성장·UI, 경쾌한 전투, 유니크 몬스터 사건)을 따라 만든 첫 지역 빌드입니다. 이름·인물·몬스터·설정은 기획서 §1 규칙대로 모두 오리지널입니다. 자세한 내용은 [슬라이스 구현 현황](docs/dev/버티컬슬라이스_구현현황.md)에 있습니다.

| 들어 있는 것 | 아직 없는 것 |
|---|---|
| 캐릭터 생성(이름·외형·시작 성향·난이도)과 도입부 | 보스, 두 번째 지역 |
| 이어진 필드 「퍼시 외곽권」(512m, 숲·강·초원·늪·마을), 낮과 밤(실제 20분이 하루) | 날씨 |
| 공명 장치: 레벨·경험치·능력치 분배, 알림 띠, 상태·장비·소지품·스킬·도감·의뢰·지도 | 방어구, 제작 |
| 퍼시 마을: 주민 7명, 의뢰 4개, 잡화점, 무기 공방(구매·강화), 여관(휴식·저장·기다리기) | 게임패드, 정식 모델·음악 |
| 전투: 총기 5종·근접 3종(쌍검 포함)·몬스터 스킬 4종, 공중 도약·벽 차기·미끄러지기, 간발의 회피와 반격, 근접 기술 | |
| 유니크 사건 「밤의 포식자」: 단서 추적 → 전조 → 조우 → 생존과 각인 | 유니크 처치 |
| 자동·수동 저장(3칸), 가 본 곳만 드러나는 지도, 탐사 단서판 | |

전투 시험장(회색 상자)은 타이틀의 **훈련장**에서 그대로 들어갈 수 있습니다.

## 실행

### 바로 플레이하기 (Windows)

GitHub의 **Actions → 테스트와 빌드 →** 가장 최근 실행의 **Artifacts**에서 `PercyFrontier-windows-x64`를 받아 압축을 풀고 `PercyFrontier.exe`를 실행합니다. 설치는 필요 없습니다. 코드 서명을 하지 않은 빌드라서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 함께 들어 있는 `README.txt`에 조작과 확인할 점이 정리되어 있습니다.

직접 빌드하려면 `tools/export.sh`를 실행합니다. 필요한 내보내기 템플릿만 받아 오고, 배포용 엔진으로 게임을 자동으로 돌려 점검한 뒤 `build/PercyFrontier-<버전>-windows-x64.zip`을 만듭니다.

### 편집기에서 실행하기

1. [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/)(표준판, .NET 아님)을 받습니다.
2. Godot 프로젝트 관리자에서 이 폴더의 `project.godot`을 가져옵니다.
3. F5로 실행하면 타이틀 화면이 나옵니다. **새로 시작**으로 캐릭터를 만들면 강하 지점에서 시작하고, **훈련장**은 전투 시험장입니다.

명령줄에서는 `godot --path .` 로 실행할 수 있습니다. 기본 렌더러는 Forward+(Vulkan·D3D12·Metal)입니다.

## 기본 조작

모든 키는 **설정 → 키 설정**에서 바꿀 수 있고, 게임 중 **Esc → 조작 안내**에서 현재 키를 볼 수 있습니다(기획서 §7).

| 입력 | 기능 |
|---|---|
| W A S D | 이동 |
| Shift | 달리기 |
| Space | 점프 · 낮은 장애물 넘기 · 공중에서 한 번 더 뛰기 · 벽에 닿은 채 누르면 벽 차기 |
| Ctrl | 앉기(달리다 누르면 미끄러지기) |
| Alt | 회피(짧은 무적, 닿기 직전에 피하면 간발의 회피: 잠깐 느려지고 반격 기회) |
| 마우스 왼쪽 | 발사 · 근접 공격(누르고 있으면 강공격) |
| 마우스 오른쪽 | 정조준 · 근접 방어(방어 시작 직후는 패링) |
| 휠 / 1 2 3 | 무기 교체(주무기 · 보조 총기 · 근접) |
| R | 재장전 |
| F | 빠른 근접 공격(총을 든 채) |
| E | 상호작용(주민과 대화, 거점, 단서 조사) |
| 4 5 6 7 | 몬스터 스킬 슬롯 1~4 |
| Q | 마지막으로 쓴 스킬 다시 사용 |
| 8 9 | 소모품(응급 봉합제 · 정화 앰플) |
| Tab | 공명 장치(상태·장비·소지품·스킬·도감) |
| M | 지도 |
| J | 의뢰 · 탐사 기록(단서판) |
| Esc | 메뉴(저장·불러오기·설정·조작 안내) |

전투 규칙 요약:
- **공격 전조**: 노란 마름모(◇)와 짧은 두 음은 패링할 수 있는 공격, 빨간 삼각형(▲)과 낮은 울음은 패링할 수 없는 공격입니다(회피하세요).
- **공명**: 약점 명중, 장갑 파괴, 패링, 처치로 모이고 몬스터 스킬에 쓰입니다.
- **분석도**: 관찰·처치·약점 처치·부위 파괴·패링·회피로 오르고, 100%가 되면 그 몬스터의 스킬이 확정 해금됩니다. 처치할 때 낮은 확률로 스킬 핵을 얻어 바로 해금될 수도 있습니다.

- **근접 기술**(근접 무기를 든 채): 회피 중·직후 공격 → 돌진 베기, 높은 곳에서 떨어지며 공격 → 낙하 베기, 달리거나 미끄러지며 공격 → 질주 찌르기.
- **나침반**: 화면 위의 금색 마름모(◆)가 추적 중인 의뢰 방향, 하늘색 점이 부활 거점입니다.

## 퍼시 외곽권 안내

- **강하 지점(서쪽, 시작)** → 길을 따라 동쪽 **퍼시**. 퍼시 주민에게 말을 걸어 의뢰를 받고, 잡화점에서 재료를 팔고, 무기 공방에서 무기를 사고 강화합니다.
- 거점(보급 비콘·여관)에서 쉬면 회복·보급·자동 저장되고, 원하는 시각까지 기다릴 수 있습니다.
- 메인 의뢰로 통신탑을 고치면 발견한 거점 사이를 **공명 이동**할 수 있습니다.
- **그늘 숲(북서)**에는 밤에만 무언가가 나타난다는 소문이 있습니다. 흔적을 모으면 탐사 단서판(J)에 조건이 정리됩니다.

## 훈련장(전투 시험장) 안내

- **보급 기지(남쪽, 시작 지점)**: 보급 거점(휴식·부활 지점), 무기 거치대(주무기·근접 무기 교체), 시험 단말기(적 무리 소환·정리, 시험용 분석 완료)
- **사격장(서쪽)**: 10m · 25m · 45m 표적과 좌우로 움직이는 표적. 표적은 머리 약점과 가슴 장갑판을 가집니다.
- **중앙 광장**: 엄폐물, 경사로와 고지대, 난간 넘기 시험(1.2m 가능 / 2.2m 불가). 시험 단말기로 부른 적이 여기 나타납니다.
- **풀숲(북서)**: 살인토끼 무리가 숨어 있습니다. 가까이 가면 바스락거리는 소리가 들립니다.
- **돌격수 들판(북동)**: 바위등 돌격수. 돌진하다 돌벽에 부딪히면 기절합니다.
- **포자 능선(동쪽)**: 포자 사수 두 마리. 전조 중 빛나는 포자 주머니를 맞히면 터집니다.

## 테스트

```bash
tools/run_tests.sh                       # 전체(단위 + 통합 + 실전 봇), 몇 분
tools/run_tests.sh test_combat_sandbox   # 이름 일부로 골라 실행
```

Windows에서는 `godot --headless --path . --import` 후 `godot --headless --path . --fixed-fps 60 res://tests/test_runner.tscn` 을 실행합니다. 푸시할 때마다 GitHub Actions(`.github/workflows/tests.yml`)가 같은 테스트를 돌립니다.

`tools/export.sh`는 빌드를 만들기 전에 배포용 엔진(내보내기 템플릿)으로 모든 스크립트·리소스를 불러오고 게임을 25초 동안 자동으로 돌려 봅니다(`tools/export_smoke.gd`). 편집기에서는 멀쩡해도 배포용 엔진에서만 실패하는 코드를 잡기 위한 것입니다.

`tools/screenshots.sh`는 게임을 가상 화면에 띄워 주요 장면(HUD, 전조, 조준경, 메뉴 등)을 PNG로 저장합니다(xvfb와 Vulkan 드라이버 필요). 필드 장면은 `xvfb-run -a godot --path . --resolution 1600x900 res://tools/field_tour.tscn -- --out=<폴더> [--only=town|unique|menus|ui]`로 찍습니다.

```
src/core/        전투 규칙, 데이터 클래스, 도감·분석도, 성장(PlayerProgress), 의뢰·단서·아이템 정의, 저장
src/main/        게임 흐름(Game), 퍼시 주민·시설(TownServices)
src/player/      플레이어, 카메라 연출, 무기 관리(사격·근접·방어·근접 기술), 스킬 시전
src/enemies/     적 공통 AI와 살인토끼·바위등 돌격수·포자 사수·훈련용 표적·밤의 포식자
src/world/       필드(지형·숲·마을·랜드마크·낮밤·환경음·야외 무리·유니크 사건), 전투 시험장, 시설, 전리품
src/ui/          HUD(나침반·의뢰 추적·알림 띠), 메뉴(타이틀·캐릭터 생성·공명 장치 창·저장), 테마
tests/           헤드리스 테스트 러너와 단위·통합 테스트
tools/           테스트·스크린샷·빌드 스크립트
docs/            기획서, 구현 현황
```

## 기술 선택

- 엔진: Godot 4.7.2, GDScript(정적 타입), Forward+ 렌더러, Jolt 물리, 물리 보간
- 1인칭 무기는 고정 시야각과 깊이 압축 셰이더로 그려 벽을 뚫고 보이지 않습니다.
- 효과음은 정식 에셋이 들어오기 전까지 코드로 합성한 임시 소리입니다.
- 글꼴: [Pretendard](https://github.com/orioncactus/pretendard)(SIL Open Font License 1.1, `assets/fonts/Pretendard-OFL.txt`). 그 밖의 모델·소리·이펙트는 모두 이 저장소에서 만든 임시 요소입니다.
