# 퍼시 외곽권 슬라이스 구현 현황 (v0.4.0)

기준 문서: [Percy Frontier 통합 기획서](../design/Percy_Frontier_통합기획서.md)
이전 단계: [전투 시험 구현 현황 (v0.1.0)](전투시험_구현현황.md)

## 방향

전투 시험 뒤에는 방향을 바꿔 **『샹그릴라 프론티어』의 구조와 감각**을 따라갔습니다. 따라간 것은 네 가지입니다.

| 따라간 점 | 이 빌드에서의 모습 |
|---|---|
| 세계·분위기 | 강하선 잔해에서 깨어나 숲을 지나 첫 마을 「퍼시」에 이르는 이어진 필드, 낮과 밤, 환경음 |
| VRMMO식 성장·UI | 세계 안의 탐사 장비 **공명 장치**: 레벨·경험치·능력치 분배, 알림 띠(레벨 업·지역 발견·스킬·의뢰·유니크), 상태창 |
| 원작식 전투 감각 | 공중 도약·벽 차기·미끄러지기, 간발의 회피(순간 슬로)와 반격, 근접 기술, 쌍검 |
| 유니크 몬스터 사건 | 흔적을 모아 조건을 추리하고, 밤에만 나타나는 존재에게서 살아남아 **각인**을 받는 사건 |

기획서 §1 규칙("캐릭터, 스토리, 몬스터, 명칭, 모델, 에셋을 오리지널로 제작한다")에 따라 이름·인물·몬스터·설정은 모두 새로 만들었습니다. 원작의 고유명사나 캐릭터는 쓰지 않습니다.

- 엔진: Godot 4.7.2 / GDScript / Forward+ / Jolt 물리
- 자동 테스트: 264개(단위 120, 통합 144 — 필드·마을·의뢰·몬스터 26종·보스·무기 드롭·그래픽 품질·유니크 사건·저장·실전 봇 포함), `tools/run_tests.sh`
- 배포용 엔진 점검: `tools/export.sh`가 훈련장 자동 교전 25초와 필드(주민 대화·시설 메뉴·공명 장치 창·유니크 사건 끝까지)를 배포용 엔진으로 돌려 본 뒤 Windows 빌드를 만든다
- 표기: ✅ 구현 · 🟡 일부 · ⬜ 아직 없음

## 3. 유니크 사건 「밤의 포식자」

기획서 §15.3의 발견 방향("빛이 사라지는 구간과 야행성 생태 흔적을 추적")을 따른 사건입니다.

- **출현 조건(세 가지 조합, §15.1)**: 밤(19:45~05:00) + 그늘 숲 깊은 곳(숲 한가운데 55m 안) + 단서 2개 이상. 조건을 채우면 확률 없이 몇 초의 전조 뒤 반드시 나타납니다.
- **단서(§15.2, 네 경로)**
  - 존재: 그늘 숲 동쪽 가장자리의 **거대한 발톱 자국**
  - 위치: 숲 한가운데로 이어진 **발자국**(밤이면 희미하게 빛남)
  - 조건: 북쪽 야영지의 **찢긴 탐사 일지**
  - 존재: 단서 없이 밤의 그늘 숲에 들어가면 **어둠 속의 푸른 눈**을 흘끗 봄
  - 사냥꾼 노라와 정문 경비의 이야기도 방향을 알려 줍니다(의뢰를 받지 않아도 단서는 모을 수 있음).
- **전조**: 풀벌레 소리가 멎고, 달빛이 사그라들고, 안개가 짙어지며, 공명 장치가 경고합니다.
- **조우**: 처음에는 이름이 `???`로 보입니다. 잠행(둘레를 돌며 간 보기) → 습격 → 어둠 속으로 사라졌다가 다른 방향에서 재등장을 되풀이합니다.
  - 발톱 휘두르기: 패링 가능(노란 전조)
  - 그림자 도약·꼬리 쓸기: 패링 불가(빨간 전조, 회피)
- **살아남는 법**: 화면 아래의 **포식자의 흥미**가 가득 차면 물러납니다. 시간이 지나면 조금씩 차고, 패링(+12)·간발의 회피(+10)·회피(+3)·약점 명중(+2.5)으로 크게 찹니다. 체력을 절반까지 깎거나 새벽이 와도 물러납니다. 이 빌드에서는 쓰러뜨릴 수 없습니다.
- **결과**
  - 생존: **밤의 포식자의 각인**(약한 야생 몬스터가 먼저 덤비지 않고 달아남 · 밤눈이 밝아짐 · 대신 강한 몬스터가 더 멀리서 알아챔), 칭호 「밤을 넘긴 자」, 경험치 300, 탐사 기록 "최초 생존", 이름 공개
  - 사망: 탐사 기록 "최초 발견"은 남고, 같은 밤에 다시 도전할 수 있음
  - 150m 넘게 달아남: 포식자가 쫓기를 멈춤(보상 없음)

## 4. 1지역 보스 「늪턱 구렁」

뱀과 악어를 섞은 길이 약 14.5m의 늪 포식자입니다. 남서 늪 끝 구렁(얕은 물이 고인 둥근 구덩이, 돌기둥 4개)의 진흙 속에 잠들어 있다가 구덩이에 들어서면 솟아오릅니다.

- **핵심 질문(§16.2): 지형 활용.** 뛰어들어 물기와 몸 굴리기 돌진이 돌기둥·구렁 벽에 부딪히면 한참 기절하고, 목 아래 붉은 턱살(약점 배율 2.5)이 빛나며 드러납니다. 포효·경직·솟구친 뒤 박혀 있을 때도 드러납니다.
- **1단계**: 턱 내리꽂기(패링 가능), 뛰어들어 물기(패링 불가), 꼬리 휩쓸기(옆·뒤에 있을 때만).
- **2단계(HP 65%)**: 포효 뒤 진흙 뱉기(둔화)와 잠수. 잠수하면 땅속으로 다가와 1초 전에 발밑에 붉은 고리를 보이고 솟구칩니다.
- **3단계(HP 30%)**: 포효 뒤 몸 굴리기 돌진, 전조가 15% 짧아집니다.
- **부위**: 눈 2(약점), 머리, 등 골판(장갑, 부술 수 있음), 가슴·배, 꼬리.
- **공정성**: 싸움터 밖에서 쏘기만 하면 진흙 속에 숨어 상처를 아물립니다. 싸움터를 떠나거나 쓰러지면 처음으로 돌아갑니다. 화면 아래에 보스 체력바.
- **첫 처치 확정 보상**: 유니크 대검 「늪턱 이빨」(도살자·톱니·묵직함), 늪턱 구렁의 핵, 늪턱 비늘판 3, 은화 300, 칭호 「늪턱을 꺾은 자」. 처치 기록은 저장되고 다시 나타나지 않습니다.

## 5. 몬스터와 무기 아이템

- 1지역 26종의 목록·차이점·상태는 [몬스터 카탈로그](../design/몬스터_카탈로그.md)에 있습니다. 모델은 모두 코드로 만든 뼈대·관 모양 몸·재질(털·비늘·가죽·키틴·골판)이고, 종족군마다 걷기·달리기·공격 동작이 다릅니다.
- **무기를 든 몬스터**(고블린)는 실제로 들고 있던 무기를 떨어뜨립니다(일반 개체는 확률, 두목·저격수는 확정).
- 떨어진 무기는 **희귀도 색 빛기둥과 이름표**로 보이고, 가까이 가면 지금 든 무기와의 비교(피해·연사·탄창 또는 약·강공격·사거리, 특성)가 뜹니다.
- **주우려면 같은 칸(주무기·보조·근접)의 무기를 버려야** 하고, 버린 무기는 그 자리에 떨어집니다. 여분은 무기 공방 창고에 맡깁니다.
- 희귀 짐승과 보스의 전리품은 무기 공방의 **전리품으로 무기를 벼린다**에서 전용 무기 5종(에픽 2 · 전설 2 · 유니크 1)이 됩니다.

## 7. 추천 경로

1. 강하 지점 → 길을 따라 동쪽 퍼시(나침반의 금색 마름모)
2. 카일에게서 메인·토끼 의뢰, 마르타에게서 바구니 의뢰, 노라에게서 추적 의뢰
3. 북동 초원 돌격수(등 뒤 배기공, 벽 충돌 기절) → 돌비늘 → 도르가 → 통신탑 복구
4. 잡화점에서 재료를 팔고 공방에서 강화
5. 남쪽 고블린 야영지에서 무기 줍기(같은 칸 무기를 버리고), 감시탑 위 저격수는 조준경 반짝임을 보고 엄폐
6. 메인 의뢰 「늪의 구렁」: 구렁 동쪽 거점에서 쉬고 보스전. 돌진을 돌기둥에 부딪히게 하기
7. 흔적을 모은 뒤 여관에서 한밤(23:00)까지 기다렸다가 그늘 숲 한가운데로

## 8. 알려진 한계

- 실제 GPU가 있는 Windows PC에서의 화면·성능은 아직 확인하지 못했습니다(이 개발 환경은 소프트웨어 렌더링). 느리면 설정 → 그래픽 품질을 보통이나 낮음으로 낮춰 주세요.
- 모델·텍스처·애니메이션·효과음은 모두 코드로 만든 것입니다(외부 에셋 사이트는 이 개발 환경에서 막혀 있음). 음악은 없습니다.
- 밤의 포식자는 처치할 수 없고, 각인은 지울 수 없습니다(이 빌드 기준).
- 게임패드는 지원하지 않습니다.

## 9. 사람이 직접 확인해 주셨으면 하는 것

- 원작 같은 "VRMMO에 들어온 느낌"이 드는가(알림 띠·상태창·성장 속도)
- 공중 도약·벽 차기·간발의 회피가 손에 붙는가
- 단서만 보고 밤의 포식자의 출현 조건을 추리할 수 있는가, 조우가 공정하게 느껴지는가(전조·재등장·흥미 게이지)
- 필드가 너무 넓거나 좁지 않은가, 밤이 너무 어둡지 않은가
- 몬스터 수와 밀도가 알맞은가, 종마다 싸우는 법이 다르게 느껴지는가
- 늪턱 구렁이 "지형을 써서 이기는" 싸움으로 느껴지는가, 너무 길거나 짧지 않은가
- 떨어진 무기의 희귀도가 한눈에 구분되는가, 버리고 줍는 흐름이 번거롭지 않은가
- 품질 설정별 화면과 속도(특히 높음·최고에서 프레임)
